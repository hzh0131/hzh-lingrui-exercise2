### 第1题
1. 德摩根定律：¬(P ∧ Q) ≡ ¬P ∨ ¬Q，¬(P ∨ Q) ≡ ¬P ∧ ¬Q。（括号打开后，与变或，或变与）
2. 一开始不清楚怎么用与非实现异或，后面上网查找了公式，发现a^b=(~a&b)|(a&~b)，再结合德摩根律，用~和&把**或**变成**与**就完美解决问题了

1. 看了教材之后知道2进制最小的数是100···000，那只需要把1向左移31位即可得到（个人感觉是9道题里最简单的一题）
### 第3题
1. 这个题比上一题略复杂一些，一开始我以为可以像上一题一样直接
```c
   int isTmax(int x) {
//#error TODO: Return 1 only when x is the maximum 32-bit two's-complement integer
    return 1>>31;
    }
```
2. 但是这显然是不对的，因为最大的数是0111···111,然后我就想到，这个Tmax有一个性质是** ~Tmax=Tmax+1 **,于是我写出了这段代码：
``` c
int isTmax(int x) {
//#error TODO: Return 1 only when x is the maximum 32-bit two's-complement integer
    return (!(~x^(x+1)));
}
```
3. 我试了几个数，发现都可以，正要做下一题的时候却发现把-1代入结果竟然也是1！所以我只能再修改一下，把x！=-1的条件加上，最后才写出正确的代码
``` c
int isTmax(int x) {
//#error TODO: Return 1 only when x is the maximum 32-bit two's-complement integer
    return ((!(~x^(x+1)))&!!(x^(~0)));
}
```
### 第4题
1. 一开始我看到这道题的时候感觉很奇怪，为什么不能让~x直接与0xAAAAAAAA作&然后取反，后面我发现这样做不符合规则，我代码中的数只能最多是2位16进制的数，于是我就沿着这个思路想用0xAA构造出0xAAAAAAAA:
``` c
int allOddBits(int x) {
    int mask = 0xAA | (0xAA << 8) | (0xAA << 16) | (0xAA << 24);
    return !((x & mask) ^ mask);
}
```
2. 因为直接把mask的构造过程带入最后return的式子特别麻烦（括号太多容易错），所以我选择先把mask单独定义，并且通过运算使其等于0xAAAAAAAA,再把mask带入return的式子中：
``` c
int allOddBits(int x) {
//#error TODO: Return 1 if every odd-numbered bit of x is set.
//int mask=0xAA;
  
return   !((~x) & ((((0xAA << 8) | 0xAA) << 16) | ((0xAA << 8) | 0xAA)));
}
```
3. **通过这题，我学会了如何用低位的16进制数构造高位的16进制数，**，但是我运行代码时，输入0xAAAAAAAA,却发现不对，后面看了一眼main函数，发现原来是main函数有一个地方写错了，至此，此题才终于完成。
```c
int main(void) {
  int x;
  if (scanf("%x", &x) != 1)//，原题为%d,%d不能输入16进制的数
    return 1;
  printf("%d\n", allOddBits(x));
  return 0;
}
```

### 第6题
1. 我一开始很快就想到把x与0x30,0x39的差（涉及到上一题的取负）与Tmin比较，再通过！，~，|等运算实现题目要求
``` c
int isAsciiDigit(int x) {
//#error TODO: Return 1 when x is between 0x30 and 0x39 inclusive.

int mask=1<<31;
//mask^((0x30+(~x+1))&mask)应该为0;
//mask^(x-(~0x39+1))&mask)应该为0;
return !((mask^((0x30+(~x+1))&mask))|(mask^((x-(~0x39+1))&mask)));
}
``` 
2. 但是这段代码忽略了一个重要问题：**边界值！**若我此时输入0x30结果是不正确的。所以我只能换个方向把=的特殊情况考虑进去，这样才改好了代码
```c
int isAsciiDigit(int x) {
    return !(((x + (~0x30 + 1)) >> 31) | ((0x39 + (~x + 1)) >> 31));
}
```
3. 这道题让我学会了做题时要考虑特殊情况（边界值，0,1等），还学会了** !!(非0的数或条件)可以使这个数或条件输出1 **

### 第7题
1. 这道题与上一题类似，一样是要找出一个mask让它与x进行运算再与y,z运算得出相反结果，但是我思考到这一步的时候思路却断掉了，于是我让ai给我提供一些思路，再ai帮助下，我知道了
> mask 只能有两种情况： 
> 1. x≠0 时，mask = 全 1（二进制所有 bit 都是 1，也就是`0xFFFFFFFF`）
> 2. x=0 时，mask = 全 0（`0x00000000`）
有了 mask 之后：
``` c
  result = ( y & mask ) | ( z & ~mask );
//解释：
//- mask 全 1:y & mask = y，z & ~mask = 0 → 结果就是 y
//- mask 全 0:y & mask = 0，z & ~mask = z → 结果就是 z
```
2. 于是我写出了下面这段代码,这样子看似没有问题，但其实`0xFFFFFFFF` 不是 int 能表示的最小值，`INT_MIN = 0x80000000`。故此时会出现有符号整数溢出的 C 标准的未定义行为。
``` c
int conditional (int x, int y, int z) {
//#error TODO: Return the equivalent of x ? y : z using bit operations.
int mask=~(!x)+1;
return (~mask&y)|(mask&z);
}
```
3. 所以我只能用<< 和 >> 来实现mask的构造
```c
int conditional(int x, int y, int z) {
//#error TODO: Return the equivalent of x ? y : z using bit operations.
    //int mask=((!x)<<31)>>31;算术右移规则：符号位是什么，高位就补什么
    return (~(((!x)<<31)>>31)&y)|((((!x)<<31)>>31)&z);//用与门实现y,z在不同条件下输出
}
```
4. 这道题让我知道了32位2进制表示下int的表示范围，知道了不能越界。

### 第9题
1. 我的思路是这样的：把任意非 0 的 x，转成全 1 的掩码（0xFFFFFFFF）；x=0 仍然保持 0
   - 如果能做到：`x != 0 → mask = 0xFFFFFFFF`；`x == 0 → mask = 0`
   - 然后 `~mask & 1`：
   - mask=0xFFFFFFFF → ~mask = 0 → `0 & 1 = 0` 
   - mask=0 → ~mask = 0xFFFFFFFF → `0xFFFFFFFF & 1 = 1` 
   就可以解决问题
2. 现在问题是**怎么把任意非 0 整数压缩成全 1 掩码**
3. 我想到了对于`x != 0`：`x` 或者 `-x` 一定是负数（最高位为 1）。即`x | (~x + 1)` 只要非 0，最高位为 1；x=0 时，`0 | 0 =0`。
4. 那么就可以利用>>构造出0和0xFFFFFFFF
5. 于是我就得到了这段代码，问题也顺利解决了
``` c
int logicalNeg(int x) {
//#error TODO: Implement logical negation without using the ! operator.
  return   1&(~((x|(~x+1))>>31)); 

}
```
